## Donde crear una pagina

- Ubica el contenido en `src/content/docs/` dentro de la categoria correcta.
- La ruta se genera segun la carpeta y el archivo.

## Rutas basadas en archivos

Ejemplo:

- Archivo: `src/content/docs/ui/accordion.mdx`
- Ruta: `/ui/accordion/` (respeta el base path configurado en el sitio)

## Convenciones

- Usa kebab-case para archivos y carpetas.
- Mantiene un tema por pagina para que sea facil de encontrar.
- Escribe titulos claros y descripciones cortas.
